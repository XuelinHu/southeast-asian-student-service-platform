## 1 引言

### 1.1 编写目的

本文档用于说明面向国际留学生的信息管理系统V1.0的需求背景、系统结构、功能模块、详细流程、数据对象、关键接口、运行部署、安全权限和测试验证情况，作为软件著作权登记材料中的软件设计说明书。

### 1.2 软件范围

面向国际留学生的信息管理系统V1.0包含前端页面、后端接口、数据库结构、运行脚本和配套配置。系统围绕留学生学习或管理业务提供登录认证、业务数据查询、核心流程处理、统计分析、权限控制和运行部署能力。

## 2 需求概要分析

### 2.1 需求背景

在中国—东盟全方位深化合作、教育对外开放持续推进的大背景下，我国已成为东盟留学生主要留学目的地，2023年中国与东盟双向留学人数已突破17.5万，越来越多东盟各国学生通过校际交换、公费留学、自费深造等多种方式来华求学，国际留学生规模持续扩大，高校国际教育业务体量大幅增长。留学生招生录取、学籍管理、日常考勤、签证备案、奖助管理、生活服务、交流活动等各类业务日趋繁杂，传统人工管理、零散表格统计的模式已无法适配规模化、规范化的管理需求。

目前多数高校针对东盟国际留学生的管理存在诸多痛点，缺乏一体化、专业化的留学生专项管理载体，存在信息数据分散、统计效率低下、流程繁琐、信息同步不及时、服务对接滞后等问题。管理人员难以高效完成留学生信息汇总、动态监管、数据统计上报，留学生也无法便捷获取校园服务、政策通知、学业进度、交流项目等相关信息，极大制约了高校国际教育管理效率与服务质量，不利于中国—东盟留学生交流工作的规范化、数字化发展。

为顺应教育数字化转型趋势，搭建标准化、一体化、智能化的国际留学生管理服务门户，整合留学生全周期信息与服务资源，打通高校管理端与留学生服务端的信息壁垒，简化管理流程、提升工作效率，同时为东盟来华留学生提供一站式信息服务保障，助力深化中国与东盟各国的教育交流与人才合作，特此研发本国际留学生信息管理系统。

### 2.2 建设目标

本软件建设目标是形成可运行、可维护、可扩展的面向国际留学生的信息管理系统，通过 Web/H5 页面与后端接口整合业务数据，减少人工处理和零散表格管理带来的低效问题，提升留学生使用体验、教师管理效率和业务数据可追溯性。

### 2.4 运行、安全和测试概要要求

系统应支持本地 Linux 服务器运行，使用 Node.js、浏览器和 MySQL 等支撑环境；应对账号、密码、数据库连接、令牌和接口地址进行脱敏；应通过真实运行页面、接口调用、数据库数据和 PDF 页数校验证明材料完整性。

## 4 总体设计

### 4.1 分层架构

系统采用浏览器前端、Node.js/Express 服务端和 MySQL 数据库的分层结构。前端负责页面展示、路由跳转、语言切换和 API 请求封装，服务端负责身份认证、权限校验、业务路由、数据聚合和异常处理，数据库负责保存用户、业务主数据、关系数据和记录数据。

### 4.2 模块协作原则

各模块按照“页面入口 - 请求封装 - 认证权限 - 业务路由 - 数据对象 - 结果展示”的链路协作。前端只保留页面状态和必要的会话信息，后端统一承担权限判断、参数校验、数据读写和错误返回，数据库表或业务对象之间通过用户身份、业务主数据、记录数据和日志数据建立关联。

## 9 安全与权限设计

1. 身份认证与访问入口控制：系统通过登录接口校验账号密码，成功后签发令牌或保存会话，未登录用户不能访问受保护页面和接口。

2. 角色权限与业务数据访问控制：系统根据学生、教师或管理员角色限制页面入口和接口范围，普通用户只能访问本人相关数据，管理角色访问统计、列表和后台查询。

3. 数据安全、脱敏、日志审计与异常处理：数据库口令、令牌密钥、真实主机、账号密码、手机号和邮箱在软著材料中统一脱敏，后台对请求异常进行捕获并保留可追溯的运行信息。
