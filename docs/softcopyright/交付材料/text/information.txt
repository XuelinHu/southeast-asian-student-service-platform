软件名称：面向国际留学生的信息管理系统V1.0
版本号：V1.0
开发的硬件环境：Linux 本地开发服务器或普通 PC 工作站，建议 4 核 CPU、16GB 内存、固态硬盘，能够同时运行 Node.js、MySQL、Chromium 和 PDF 导出工具。
运行的硬件环境：Linux/Windows 应用服务器或教学管理终端，建议 2 核 CPU、4GB 内存、20GB 可用磁盘空间；用户通过浏览器或 H5 页面访问。
开发该软件的操作系统：Linux
软件开发环境 / 开发工具：Node.js、npm、Express、Vue/Vite 或静态 H5、MySQL、Chromium、命令行终端、Git。
该软件的运行平台 / 操作系统：浏览器 Web/H5 应用，后端运行于 Node.js，数据库运行于 MySQL。
软件运行支撑环境 / 支持软件：Node.js、MySQL、现代浏览器、静态资源服务、JSON API 服务。
编程语言：JavaScript、Vue、HTML、CSS、SQL、Node.js 脚本。
源程序量：本次源码稿选入 18 个真实源码、配置、SQL 或脚本文件，不包含第三方依赖、构建产物、截图和 PDF。
开发目的：在中国—东盟全方位深化合作、教育对外开放持续推进的大背景下，我国已成为东盟留学生主要留学目的地，2023年中国与东盟双向留学人数已突破17.5万，越来越多东盟各国学生通过校际交换、公费留学、自费深造等多种方式来华求学，国际留学生规模持续扩大，高校国际教育业务体量大幅增长。留学生招生录取、学籍管理、日常考勤、签证备案、奖助管理、生活服务、交流活动等各类业务日趋繁杂，传统人工管理、零散表格统计的模式已无法适配规模化、规范化的管理需求。目前多数高校针对东盟国际留学生的管理存在诸多痛点，缺乏一体化、专业化的留学生专项管理载体，存在信息数据分散、统计效率低下、流程繁琐、信息同步不及时、服务对接滞后等问题。管理人员难以高效完成留学生信息汇总、动态监管、数据统计上报，留学生也无法便捷获取校园服务、政策通知、学业进度、交流项目等相关信息，极大制约了高校国际教育管理效率与服务质量，不利于中国—东盟留学生交流工作的规范化、数字化发展。为顺应教育数字化转型趋势，搭建标准化、一体化、智能化的国际留学生管理服务门户，整合留学生全周期信息与服务资源，打通高校管理端与留学生服务端的信息壁垒，简化管理流程、提升工作效率，同时为东盟来华留学生提供一站式信息服务保障，助力深化中国与东盟各国的教育交流与人才合作，特此研发本国际留学生信息管理系统。
面向行业 / 领域：教育信息化、国际留学生服务、在线学习与教学管理。
软件的主要功能：认证与角色模块面向学生、教师、管理员，提供统一登录、JWT 签发、角色鉴权和会话保持，主要通过/api/auth/login实现，并围绕users等数据对象完成业务处理。学生档案模块面向学生、教师、管理员，提供本人档案查询、学生列表和学生基础信息管理，主要通过/api/students/*实现，并围绕students、classes、nationalities等数据对象完成业务处理。教师管理模块面向管理员，提供教师列表、教师工号、学院和教师类型维护，主要通过/api/teachers/*实现，并围绕teachers、users等数据对象完成业务处理。成绩适配模块面向学生、教师、管理员，提供外部成绩录入、规则适配、审核和学生成绩查询，主要通过/api/grades/*实现，并围绕grade_records、grade_rules、external_schools等数据对象完成业务处理。风险查询模块面向教师、管理员，提供签证、成绩、学习和住宿风险聚合查询，主要通过/api/management/risks实现，并围绕visas、grade_records、study_records、dormitories等数据对象完成业务处理。统计分析模块面向教师、管理员，提供学生数、教师数、签证预警和成绩异常统计，主要通过/api/management/dashboard实现，并围绕students、teachers、visas、grade_records等数据对象完成业务处理。系统支持用户在真实运行页面中完成登录、查看、查询、提交、统计或管理操作，并通过后台接口和数据库实现数据保存、权限限制、业务结果返回和运行检查。本次软著材料重新采集了 H5 竖屏校准截图和桌面管理截图，能够证明页面真实可运行、业务数据真实加载、核心流程可交互。
软件的技术特点：系统采用浏览器前端、Node.js/Express 后端和 MySQL 数据库的分层结构，前端负责页面渲染、语言切换、表单交互和请求发起，后端负责认证鉴权、角色控制、业务接口、数据查询和异常处理，数据库保存用户、角色、业务主数据、记录数据和统计数据。系统支持本机 Linux 环境部署，截图和 PDF 导出阶段通过本机回环地址访问本地服务，敏感配置在文档和源码稿中统一脱敏。
